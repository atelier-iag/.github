# AGI Research Roadmap

Hands-on exploration of the main research directions toward AGI.

## Roadmap

1. Build practical expertise across the main research paradigms.
2. Reproduce a reference baseline for each paradigm.
3. Reimplement the core mechanisms.
4. Add and evaluate modern improvements.
5. Compare approaches under a common experimental framework.
6. Explore combinations and formulate new research hypotheses.
